## 명시적 계산 규약

- CASH는 원화 현금이며 가격=1, 환율=1. 미국 달러 현금 계정이 아니다.
- 종가·SMA·EMA는 표시만 정수로 반올림하며 계산값을 반올림하지 않는다.
- 미완성 월의 SMA/모멘텀은 기준일까지의 마지막 가격을 해당 월 값으로 사용한다.
- 실행 주기의 월말은 달력 말일이다. 실제 주문은 사용자가 다음 거래일에 한다.
- 신호 시장 분류는 메타데이터다. 미국 신호로 한국 ETF를 매매할 수 있다.
- 상대 가격 조건은 가격 수준 비교이며 환율환산 수익률 비교가 아니다.
- 데이터 누락·오래된 가격·미지원 조건·없는 주문 대상은 미충족으로 간주하지 않고 매매 차단한다.
- 순위 동률은 티커 오름차순. 후보 중 한 종목이라도 가격이 없으면 전체 판단을 차단한다.
- 특정 비중 설정 후 잔여 금액은 나머지 현재 평가액 비율로 분배하며 모두 0이면 균등 분배한다.
- AND/OR 중첩 그룹·괄호 편집은 이 버전에 포함하지 않는다. 원본의 선형 조건 카드에 대응한다.

## 유지한 운영 경계 / 미구현 서비스

원본 설정 화면의 KRX·한국은행 API 선택, D1 캐시, 06:00 크론, KIS 주문,
Cloudflare 이관은 원본에서도 변경 핸들러가 비어 있던 서비스 설정이다.
이 배포에서는 Yahoo 가격·15분 신호 캐시·수동 기준일 판정·GitHub/Streamlit으로 대체한다.
서버가 꺼져 있어도 실행되는 스케줄러, 이메일/푸시 전송, KIS 주문은 구현하지 않았다.
디자인 조절 패널·애니메이션·드래그앤드롭은 옮기지 않았으며, 카드/표 편집을 제공한다.

기존 규칙은 자동 변환하거나 덮어쓰지 않는다. Studio에서 초안을 검토하고 적용하면
schema_version=2로 전환된다. 초안 기본값은 보유 유지이며 사용자가 실제 조건을 지정해야 한다.
이전 버전은 Strategies에서 비활성 사본을 만든 뒤 변경한다. GitHub가 개인 전략 데이터를 저장하지 않는다.
브라우저 세션의 저장은 영구 저장이 아니다. Data에서 복사해 시트에 저장해야 한다.

실제 Streamlit Cloud 배포 성공, 실시간 Yahoo 가용성, 사용자 시트 권한은 별도 운영 확인이 필요하다.
