## 가격·환율·평가

평가액 = 수량 × **비수정 종가** × 원화 환율. 수정종가는 전략의 신호 계산에만 선택적으로 사용한다. 요청일·실제 가격일·조회 시각·통화·가격/환율 출처를 평가 원본에 보존한다. 휴장일은 직전 거래일을 표시하고 장중 가격은 확정하지 않는다. 미국 신호의 당일 장 마감 전에는 해당 계좌를 차단한다.

환율은 Yahoo KRW=X의 일별 값이다. 뉴욕 17:20 이전에는 당일 관측값을 사용하지 않으며, 3일보다 오래된 값은 차단한다. 통화시장 전용 휴일 달력은 아직 없으므로 긴 연휴에는 보수적으로 차단될 수 있다. 신호·가격 공급원을 주입할 수 있어 다른 어댑터를 추가할 수 있다.

수동 종가는 출처·사유·거래일을 요구한다. 수동 종가가 있어도 SMA 등 원시 신호가 없으면 조건을 차단한다. 0원 계좌의 비중은 0이다. 비활성 전략도 자산 평가는 하고 거래는 만들지 않는다. 혼합 ETF는 `classification_json`에 분류별 비율을 합계 100으로 입력한다. 이 분류를 과거 스냅샷에도 보존한다.

## 규칙 계약

14종 조건: SMA 상회/하회, EMA 상회/하회, 낙폭 상회/하회, 모멘텀 순위, 기간 수익률 기준, 절대 가격 상회/하회, 두 가격 비교, 일정, 목표 괴리, 수동 외부 지표.

11종 행동: 유지, 전량 현금화, 대상 이동, 비중 설정, 현금 일부 매수, 전체 목표 복원, 지정 종목/역할 복원, 지정 범위 대체 전환, 목표 비중까지 현금 매수, 트리거 표시, 메시지 표시.

- 조건은 왼쪽부터 결합한다: `(A OR B) AND C`. 중첩 괄호·NOT·돌파 상태는 지원하지 않는다.
- 한 조건이라도 UNKNOWN이면 양쪽 행동을 차단한다. 순위 후보 누락도 동일하다. 동률은 티커 오름차순이다.
- SMA는 월별 마지막 가격 N개의 평균, EMA는 N거래일·adjust=False, 낙폭은 최근 N거래일 고점 대비, 모멘텀은 N개월 수익률이다.
- 기본은 현재 월의 기준일까지 값을 포함한다. 이전 확정 월봉만 선택하면 SMA 평균·월별 모멘텀에서 현재 월을 제외한다. SMA 비교가격은 지정일 종가다.
- 조건 평가 주기와 목표 복원 행동의 주기를 별도로 지정한다. 월별 방어 판단과 분기 복원을 조합한다.
- 수동 외부 지표는 관측일·발표일·출처를 요구하고 기준일 이후 발표값은 차단한다. 사후 개정값 자동 검증은 하지 않는다.
- 기존 `sma_filter_rebalance`는 지정 티커마다 독립적으로 SMA를 검사한다. 하나라도 하회하면 전체 역할을 매도하는 규칙과 다르다.
- 구형 schema_version 1 시각 규칙은 자동 변환하지 않는다. 전략실에서 검토·적용해야 활성 계산이 가능하다.

## 주문·체결

목표 차액과 수량에 따른 예상 거래액을 구분한다. 목표 괴리가 허용 %p 이하면 거래하지 않는다. 수량은 거래 단위로 절삭하고 보유 초과 매도를 막는다. 매수 한도는 기존 CASH에서 유보액을 뺀 금액이며 같은 주문안의 매도대금은 쓰지 않는다. 매수 우선순위는 부족 금액이 큰 종목, 동률이면 티커순이다.

실제 체결 입력은 모두 양수이며 방향은 확정 주문에서 가져온다. 실제 금액 = 수량 × 단가 × 환율을 검증한다. 체결일은 예정일 이후의 실제 거래일이어야 한다. 누적 체결은 확정 수량을 넘을 수 없고, 동일 체결 ID는 재반영할 수 없다. 하나의 오류가 있으면 전체 묶음을 반영하지 않는다. 취소는 잔여 주문을 닫으며 기존 체결을 되돌리지 않는다. 실제 브로커 취소를 전송하지 않는다.

체결 전 스냅샷은 이후 거래로 바뀌지 않는다. 실제 체결이 반영된 다음 평가에서는 갱신된 보유수량을 사용한다.

## 저장·복원

평가 ID는 입력·설정·가격·신호·주문·엔진 버전으로 결정한다. 같은 실행 확정은 중복되지 않는다. 같은 날짜의 변경 기록은 개정 사유를 요구하고 원본을 보존한다. 성과에는 날짜·전략별 최신 개정만 반영한다.

Evaluations는 원시 가격과 당시 주문을 20,000자 단위로 나눠 시트 셀 제한을 피한다. 모든 조각이 있어야 복원된다. JSON 백업에는 8개 원장과 현재 평가·주문 수정·체결 입력·수동 가격도 포함한다. 아직 제출하지 않은 폼의 타이핑 내용은 백업되지 않는다.

Apps Script 연결은 앱 비밀번호를 확인한 후 세션 최초 1회 읽는다. 저장은 명시적 버튼으로 수행한다. 요청 ID로 응답 손실 후 재시도를 식별하고, 전체 자료 지문으로 다른 세션·직접 시트 편집과 충돌을 감지한다. ScriptLock과 이전 원장 복사본으로 중단된 저장을 복구한다. Google Sheets는 완전한 트랜잭션 DB가 아니므로 저장 중 직접 시트를 동시에 편집하지 않아야 한다. 세부 절차는 SHEETS_SETUP.md에 있다.

수동 복사 경로에서는 저장 완료를 추정하지 않는다. 다시 읽었을 때 기록 ID뿐 아니라 수량·종가·환율·평가액·개정이 일치하는지 확인한다.

## 성과

불규칙 평가일 사이의 입출금을 날짜 가중한 Modified Dietz를 연결한다. 정확한 TWR이라고 표시하지 않는다. 투자손익·순외부 입출금·기간 수익률·CAGR·관측일 MDD·XIRR을 구분한다. 내부 이체는 계좌별 양쪽을 기록하고 전체에서는 상쇄한다. 날짜별 계좌 구성이 다르면 전체 성과를 차단한다.

분석 시작·종료일과 전략 버전의 연속 적용 기간을 선택한다. 변동성·Sharpe·Sortino는 동일 일자 또는 월말의 연속 월간 수익률 12개 이상일 때만 연 12회·위험무이자율 0%로 계산한다. 벤치마크는 동일 평가일의 원화 환산 비수정 종가로 비교한다. 배당은 제외하며 포트폴리오 잔고에 남은 분배금과의 차이를 표시한다.

## 검증과 남은 확인

자동 검증은 고정 시계열과 Streamlit AppTest, 실제 Code.gs를 실행하는 모의 시트 어댑터로 수행한다. AC-01~05,07,09~21의 주요 구현 경로를 테스트하며, 비용·반복 상태 관련 부분은 사용자 제외 결정에 따른다. 실제 사용자 7개 전략과 운영 연동(AC-22), 연간 전략(AC-23 중 연간 부분)은 완료로 표시하지 않는다.

입력 표는 이름이 다른 필수 열을 명시적으로 연결할 수 있다. 전체 분류 목표는 편집·검증 후 실제 비중과 비교한다. 추가 남은 범위: 연간 전략 유효기간 예약, 기존 앱의 즐겨찾기·최근 티커·모바일 전용 카드·납입한도 추적. [격차표](REVIEW_2026_09_25.md)를 참고한다.
